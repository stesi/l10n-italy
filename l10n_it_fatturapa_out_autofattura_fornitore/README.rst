==================
Emissione Autofattura Elettronica per acquisti da Imprese Agricole esonerate
==================

Questo modulo consente di generare il file .xml sull'acquisto effettuato presso un impresa agricola esonerata (volume di affari < 7.000 €), o altro soggetto economico esonerato per il quale vige l'obbligo di emissione dell'autofattura in capo all'acquirente.

Configuration
=============
Dopo aver installato e attivato il modulo, occorre attivare il flag su campo "Permetti esportazione fattura elettronica fornitore" in tab "Fattura elettronica" del partner.

Usage
=============
Registrare e confermare l'acquisto effettuato presso l'agricoltore come fattura fornitore > esportare il file .xml ed inviare allo SDI
